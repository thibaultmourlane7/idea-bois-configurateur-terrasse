# Référentiel visuel produit — V0.14

## Principe
Aucune photo n'est qualifiée de « texture réelle » sans URL média IDEA Bois directement vérifiée.

### Vérifié
Padouk :
- image média IDEA Bois vérifiée ;
- utilisée comme texture photo dans la 2D/3D et comme visuel catalogue.

### Rendu catalogue
Pour les autres gammes non encore mappées vers une URL média directe :
- le rendu reprend l'essence, la teinte et le profil publiés ;
- aucune photo tierce n'est utilisée ;
- `imageStatus = catalog-described`.

Le branchement d'une nouvelle photo produit ne nécessite aucune modification du moteur : il suffit d'ajouter l'URL média vérifiée au référentiel visuel.
