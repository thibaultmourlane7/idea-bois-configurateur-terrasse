# Roadmap vers le cahier V3

## Déjà présent V0.5
Moteur séparé de l'UI, rectangle + L, 2 orientations, calepinage, coupe/chutes, 2D, aperçu 3D, chiffrage fournitures, sauvegarde, contrat ERP, pont SpeedArti, tests et balises.

## P0
Catalogue réel IDEA Bois, règles fabricants versionnées, sous-structure, plots, fixations, rives, compatibilités, stock par dépôt, devis/panier/commande ERP, erreurs ERP, export PDF.

## P1
Dessin libre, obstacles/réservations, niveaux/pentes, escaliers, éclairage, comparateur, multi-dépôts, partage/QR, portail conseiller, versions verrouillées, soleil/ombre, environnement jardin.

## P2
Rendu photoréaliste, AR, LiDAR, import plan/photo assisté, terrasse + clôture, multi-niveaux avancé.

## Règle permanente
Aucun calcul de temps de pose, d'heures ou de coût de main-d'œuvre.
