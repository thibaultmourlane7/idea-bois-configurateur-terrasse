# Textures locales

La V0.14.2-A utilise temporairement des textures distantes CC0 déclarées dans `src/catalog/productTextures.ts`.

Ce dossier est réservé au vendoring local des fichiers validés pendant V0.14.2-B afin de :
- supprimer la dépendance réseau externe ;
- figer les versions utilisées ;
- optimiser les tailles d'images ;
- ajouter les cartes PBR.

Ne jamais ajouter un fichier sans sa source, sa licence et son statut exact/proche.
