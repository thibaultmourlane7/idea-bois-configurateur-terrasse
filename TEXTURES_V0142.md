# Bibliothèque textures — V0.14.2-A

## Architecture
- `src/catalog/productTextures.ts` : bibliothèque des matériaux ;
- `src/visual/resolveBoardTexture.ts` : résolution BoardSpec -> texture ;
- `src/components/Plan2D.tsx` : application lame par lame ;
- `src/components/Preview3D.tsx` : même matériau en aperçu 3D ;
- `src/components/SideView.tsx` : même matière sur le dessus et les rives.

## Références visuelles complémentaires
- Cumaru : Lightbeans / Platinum Woods — Cumaru Square Edge Wood Deck ;
- Garapa : Lightbeans / Platinum Woods — Garapa Square Edge Wood Deck ;
- Ipé : Lightbeans / Platinum Woods — Ipe Deck ;
- Padouk : Arroway — African Padauk Veneer ;
- Pin et SILVADEC : fiches IDEA Bois correspondantes.

Ces références servent à calibrer le rendu. Les fichiers de texture intégrés dans la démo restent les bases CC0 déclarées dans le manifeste.

## Remplacement futur
Une texture `close` peut être remplacée par `exact` en modifiant uniquement le manifeste.
Aucune règle de prix, quantité, structure ou catalogue ne doit changer.
