# Tâche 9 — Choix explicite de lambourde Garapa / Padouk — V0.19.6

Date : 2026-09-23

## Objectif
Ne plus imposer silencieusement une seule famille de lambourde lorsque IDEA Bois documente plusieurs solutions compatibles.

## Garapa
IDEA Bois indique explicitement :
- support de pose : lambourde bois exotique **ou** lambourde pin Classe 4 ;
- la lambourde exotique 65×42 mm est compatible avec le Garapa.

Sources :
- https://www.idea-bois.com/art-lame-terrasse-bois-exotique-garapa-lisse-l-4-00-m-145x21-mm-visser-3471.htm
- https://www.idea-bois.com/art-lambourde-bois-exotique-65x42-mm-pour-terrasse-long-3-95-m-3221.htm

## Padouk
IDEA Bois indique des lambourdes robustes, massives ou traitées, notamment pin maritime / tali / pin sylvestre, espacées de 40 à 50 cm. Les kits Padouk publiés utilisent des lambourdes 60×40 mm L.2,40 m. La page de la lambourde exotique 65×42 mm indique également qu’elle est adaptée au Padouk.

Sources :
- https://www.idea-bois.com/art-lame-terrasse-bois-exotique-padouk-lisse-longueur-2-45-m-120-x-21-mm-4760.htm
- https://www.idea-bois.com/art-lambourde-bois-exotique-65x42-mm-pour-terrasse-long-3-95-m-3221.htm

## Fonctionnement
Pour Garapa et Padouk, l’étape Support propose désormais :
- **Pin Classe 4 — 60×40 mm**
- **Bois exotique — 65×42 mm**

Sans choix :
- aucune règle structurelle définitive n’est appliquée ;
- le calcul technique reste bloqué/à confirmer ;
- aucune substitution n’est faite automatiquement.

Avec choix :
- Pin Classe 4 : longueurs commerciales 2,40 / 3,00 m ;
- Bois exotique : longueurs 1,85 / 2,45 / 3,95 m ;
- entraxe retenu : 500 mm, dans la plage documentée 40–50 cm pour ces cas.

## Persistance
Le choix est enregistré dans :
- la sauvegarde locale ;
- le lien de partage (snapshot V8).

Un changement vers une autre recette de lame réinitialise le choix afin d’éviter de transporter silencieusement une décision d’un produit vers un autre.
